* dotfiles
** Get started
Clone this repo
#+begin_src bash
git clone https://github.com/antonsakhanovych/dotfiles
#+end_src

Navigate to the cloned directory
#+begin_src bash
cd dotfiles
#+end_src

Link the files to the home directory
#+begin_src bash
stow -S -t ~ --no-folding .
#+end_src

**** Setup
1. Add the following into /etc/polkit-1/rules.d/20-shutdown-reboot.rules
   ```javascript
   polkit.addRule(function(action, subject) {
    if ((action.id == "org.freedesktop.consolekit.system.stop" ||
         action.id == "org.freedesktop.consolekit.system.restart") &&
        subject.isInGroup("wheel")) {
            return polkit.Result.YES;
    }
});
   ```
2. Make the following symlinks in /etc/pipewire/pipewire.conf.d directory
   /etc/pipewire/pipewire.conf.d/10-wireplumber.conf -> /usr/share/examples/wireplumber/10-wireplumber.conf
   /etc/pipewire/pipewire.conf.d/20-pipewire-pulse.conf -> /usr/share/examples/pipewire/20-pipewire-pulse.conf

**** Setup
1. Add your user into storage and plugdev groups
2. add the following into /etc/polkit-1/rules.d/10-udisks2.rules
   ```javascript
   polkit.addRule(function(action, subject) {
    if ((action.id == "org.freedesktop.udisks2.filesystem-mount-system" ||
         action.id == "org.freedesktop.udisks2.filesystem-mount" ||
         action.id == "org.freedesktop.udisks2.filesystem-unmount-others" ||
         action.id == "org.freedesktop.udisks2.eject-media" ||
         action.id == "org.freedesktop.udisks2.eject-media-other-seat" ||
         action.id == "org.freedesktop.udisks2.eject-media-system" ||
         action.id == "org.freedesktop.udisks2.encrypted-unlock" ||
         action.id == "org.freedesktop.udisks2.power-off-drive" ||
         action.id == "org.freedesktop.udisks2.power-off-drive-other-seat" ||
	action.id == "org.freedesktop.udisks2.filesystem-unmount-others") &&
	subject.isInGroup("storage")) {
        return polkit.Result.YES;
    }
});
   ```
